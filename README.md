# Django Idempotency

A lightweight idempotency library for Django and Django REST Framework APIs.

## Goals

- Prevent duplicate execution of API operations.
- Support Redis-backed idempotency records.
- Handle concurrent requests safely.
- Replay stored responses when appropriate.
- Provide a clean API for Django and Django REST Framework.
- Include comprehensive tests.
